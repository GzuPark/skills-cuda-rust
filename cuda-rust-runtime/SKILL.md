# CUDA Rust host runtime

Identify the resolved versions and runtime APIs already used by the project before changing host code. The shared runtime includes `cuda-bindings`, `cuda-core`, and `cuda-async`; prefer source, examples, and API documentation matching those versions or Git revision. The snapshot's [host API reference](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/reference/host-api.md) and [device operations guide](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/guide/device-operations.md) describe that snapshot. If the project's version or matching source cannot be established, say so and label cross-version guidance as unverified.

Trace ownership and lifetimes of each device buffer through allocation, transfer, launch, completion, and reuse. Keep borrowed or externally owned resources alive until GPU work completes. Preserve ordering on the stream used for dependent operations. Across streams, record an event after the producer and make the consumer stream wait before it accesses the buffer. Ensure the final consumer completes before reuse or destruction; order any asynchronous free after that last use. Check the version-specific event and ownership APIs before writing code.

For external pointers, libraries, or streams, inspect the version-matched [interoperability guide](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/guide/interoperability.md). Document unsafe ownership, device, lifetime, aliasing, and synchronization invariants. The snapshot's [foreign allocation example](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-examples/examples/cudarc_interop.rs) and [DeviceAllocation contract](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cuda-async/src/device_buffer.rs) show one approach; check the target version's actual API and safety contract. For a mixed SIMT and Tile pipeline, consult the [inter-kernel example](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cuda-oxide/crates/rustc-codegen-cuda/examples/cutile_inter_kernel/README.md); do not infer support for arbitrary intra-kernel interoperability.

Validate results against a host reference and run relevant asynchronous or interop tests on a compatible GPU. Report any unavailable GPU checks. When available, the repository's `llms.txt` indexes additional sources.
