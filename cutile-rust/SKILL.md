# cuTile Rust

Identify the project's resolved `cutile` version, Rust toolchain, CUDA toolkit, driver, and GPU before choosing examples. Prefer documentation and examples from that exact release or Git revision. The snapshot's [README](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/README.md) and [compatibility guide](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/reference/compatibility.md) describe that snapshot; they do not establish another release's requirements. If the resolved version or matching source is unavailable, say so and label cross-version guidance as unverified.

Start from a version-matched tutorial or example. Distinguish host tensor setup from the device tile program. Partition mutable outputs into disjoint regions, check shapes and boundary behavior, and use the generated operation with the execution mode required by the project. The [tensors and tiles guide](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/guide/tensors-and-tiles.md) and [vector addition tutorial](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/tutorials/02-vector-addition.md) describe the snapshot's model.

cuTile compiles kernels through Tile IR at runtime. For compilation or launch failures, inspect the version-matched [JIT guide](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-book/guide/jit-compilation.md). Do not assume SIMT thread indexing or synchronization APIs apply to a tile program. For unsafe pointers or external allocations, document and verify the ownership, lifetime, and synchronization contracts.

For JIT compatibility, distinguish the driver version reported by `nvidia-smi`, the installed toolkit, the `tileiras` actually selected by the process, the cuTile version, and the GPU compute capability. Check the target release's feature and architecture requirements before recommending FP4 or another hardware-specific operation. In the fixed snapshot, `CUTILE_SETUP_DIAGNOSTICS=1` reports discovery and `CUTILE_TILEIRAS_PATH` can override the assembler; verify these options in the target version before using them. The snapshot's [compiler README](https://github.com/NVIDIA/cuda-rust/blob/0d62b682be98a12897867b23ff0dfc0d765e9fa3/cutile-rs/cutile-compiler/README.md) and compatibility guide provide starting points. Do not infer the selected assembler from `nvcc` or the driver alone. If documentation disagrees about bytecode support, check the actual writer and selected assembler rather than inferring support from the feature table alone.

Run the project's build and correctness tests, including non-divisible shapes where supported. Report when GPU execution was unavailable. For host runtime or SIMT work, use the relevant CUDA Rust skill if installed. When available, the repository's `llms.txt` indexes additional sources.
